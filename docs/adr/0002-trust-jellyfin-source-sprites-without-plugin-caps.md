# Trust Jellyfin Source Sprites without plugin-specific resource caps

Trickplay Cropper v1 treats Jellyfin-owned Source Sprites and their metadata as trusted input and adds no numeric cap for source dimensions, pixel counts, file length, decoded or encoded bytes, CPU time, or wall-clock time. The encoder still uses checked arithmetic, validates dimensions and crop bounds, limits concurrent decodes to four, and never allocates a complete decoded Source Sprite bitmap, but managed or native resource exhaustion remains outside the recovery guarantee. The plugin snapshots source length and mtime once and does not lock or revalidate Jellyfin-owned files across encoding. This deliberately favors compatibility with Jellyfin-generated data over plugin-specific rejection and source-mutation protocols, accepting that abnormal trusted inputs or concurrent replacement can fail a request or affect the server process.
